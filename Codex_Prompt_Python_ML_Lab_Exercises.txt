PYTHON AND MACHINE LEARNING LAB EXERCISES Codex Instructions and
Exercise Details

PURPOSE Generate complete, simple, beginner-friendly lab programs for
all the exercises below. Follow each title exactly. Create a separate
Python file for each Python exercise, with clear filenames such as
01_math_library.py, 02_numpy_arrays.py, and so on. For Julius AI, Bricks
AI, Levity, and Teachable Machine, provide practical step-by-step
instructions and any required sample data or setup details rather than
pretending these external platforms are Python libraries.

GENERAL CODING RULES 1. Keep the code simple and suitable for an MCA
student lab record. 2. Use beginner-friendly variable names and
straightforward logic. 3. Comments are optional. Prefer no comments; if
needed, use only very simple, short comments. 4. Wrap the main program
logic in try-except so common errors are handled gracefully. Catch
specific exceptions when practical. Do not hide errors with a bare
except or silently ignore them. 5. For menu-driven programs, use while
True and match-case (Python 3.10+). Include an exit option and break
when selected. 6. Display all menu choices in a single print statement
using the style: print(“ for Ceil() for Factorial() to Exit”) Do not use
a separate print statement for every menu option. 7. Validate user input
and show a simple helpful message for invalid choices or invalid values.
8. Do not add unnecessary classes, functions, packages, or advanced
techniques. 9. Use realistic, small sample data when a dataset is not
specified. Clearly identify any data that is manually created. 10. Each
exercise should include: Title, Aim, Program or Procedure, Sample
Output, and Result. 11. Use this common result for ordinary Python
exercises: “Thus, the above code is executed and the output verified
successfully.” 12. For visualizations and external AI platforms, use a
result statement describing the actual output, such as a chart,
dashboard, analysis, or trained model. 13. Make sure code runs with the
stated dependencies. Include the pip install command when a third-party
package is needed. 14. Do not claim that an external AI platform was
executed or that a model was trained unless the instructions actually
perform that task. 15. Keep the solution aligned with the exact lab
title and do not turn a simple exercise into a large project.

USER INPUT FOR MACHINE LEARNING ALGORITHMS For all supervised
learning/classification/regression exercises, train the model on the
dataset and then ask the user to enter values for a new sample. Pass
those entered values to the trained model and display the predicted
class or value. Do not only print predictions for the training dataset.
Also show a basic evaluation metric where appropriate. For clustering,
ask the user to enter a value or sample to assign to a cluster where
meaningful. Explain briefly when a prediction depends on the features
available in the chosen dataset.

MENU AND ERROR-HANDLING DETAILS For Math library and other exercises
where multiple operations are appropriate, offer a menu using while True
and match-case. Put all options in one print statement, for example:
print(“ for Ceil() for Factorial() for Square Root to Exit”) Use
try-except around input conversion and operations. Reject invalid inputs
such as a negative number for factorial or a negative value for square
root when using real-valued math.

EXERCISE DETAILS

1.  Implement the functions using Math library Aim: To write a Python
    program to perform mathematical operations using the Math library.
    Requirements:

-   Use import math.
-   Provide a menu using while True and match-case.
-   Include useful operations such as ceil(), floor(), factorial(),
    sqrt(), pow(), fabs(), gcd(), and pi-related calculation if
    appropriate.
-   Get the required number(s) from the user for each selected
    operation.
-   Handle invalid input and invalid mathematical values gracefully.

2.  Create and manipulate multidimensional arrays using NumPy Aim: To
    write a Python program to create and manipulate multidimensional
    arrays using the NumPy library. Requirements:

-   Create one-dimensional, two-dimensional, and three-dimensional
    arrays.
-   Demonstrate indexing, slicing, shape, dimensions, reshaping,
    addition, and multiplication.
-   Use user input where practical, or clearly label the sample array
    values.
-   Keep the output readable.

3.  Perform statistical functions using Statistics library Aim: To write
    a Python program to perform statistical operations using the
    Statistics library. Requirements:

-   Use the statistics module.
-   Ask the user to enter a list of numeric values.
-   Provide a menu using while True and match-case for mean, median,
    mode, variance, and standard deviation.
-   Handle empty input and cases where a statistic cannot be calculated.

4.  DataFrame implementation using Pandas Aim: To write a Python program
    to create and manipulate DataFrames using the Pandas library.
    Requirements:

-   Create a DataFrame from simple sample data or user input.
-   Demonstrate displaying, selecting columns, adding a column, updating
    a value, and deleting a column or row.
-   Use a menu with while True and match-case if it fits naturally.

5.  Handling the missing values in a dataset Aim: To write a Python
    program to identify and handle missing values in a dataset using
    Pandas. Requirements:

-   Create or load a small dataset containing missing values.
-   Display missing-value counts.
-   Demonstrate removing missing rows and filling missing numeric values
    using a suitable method such as mean.
-   Show the dataset before and after handling missing values.

6.  Load a dataset and perform data analysis Aim: To write a Python
    program to load a dataset and perform data analysis using Pandas.
    Requirements:

-   Use a small built-in scikit-learn dataset or a clearly identified
    sample CSV.
-   Load the data into a DataFrame.
-   Display the first rows, column names, row/column count, data types,
    and useful basic analysis.
-   Avoid relying on a local file that the user has not been given.

7.  Load a dataset and display its structure with statistical summaries
    using Pandas Aim: To write a Python program to load a dataset and
    display its structure and statistical summaries using Pandas.
    Requirements:

-   Load a dataset.
-   Display head(), tail(), shape, columns, info(), describe(), and
    suitable categorical summaries if present.
-   Keep the output suitable for a lab record.

8.  Load a dataset and display its structure with graphs using Pandas
    and Matplotlib Aim: To write a Python program to load a dataset and
    visualize its structure using Pandas and Matplotlib. Requirements:

-   Load a dataset.
-   Display basic structure.
-   Draw suitable plots such as a histogram, bar chart, and scatter plot
    using Pandas plotting or Matplotlib.
-   Add chart titles and axis labels.
-   Call plt.show() and handle missing or nonnumeric columns
    appropriately.

9.  Perform Visualization using Seaborn Aim: To write a Python program
    to visualize a dataset using the Seaborn library. Requirements:

-   Load a suitable dataset.
-   Use Seaborn to draw suitable plots, for example a scatter plot,
    histogram, box plot, or heatmap.
-   Add titles and labels where appropriate.
-   Display the plots and use a specific result statement confirming the
    visualization.

10. Implementation of Covariance and Correlation Aim: To write a Python
    program to calculate covariance and correlation between variables in
    a dataset. Requirements:

-   Use numeric data with at least two variables.
-   Calculate covariance and correlation using Pandas or NumPy.
-   Display the covariance matrix and correlation matrix.
-   Optionally show a correlation heatmap if Matplotlib/Seaborn is
    installed.
-   Explain briefly that correlation does not prove causation.

11. Perform Normalization in a given dataset Aim: To write a Python
    program to normalize the values in a given dataset using appropriate
    normalization techniques. Requirements:

-   Demonstrate Min-Max normalization and, if useful, standardization.
-   Use scikit-learn preprocessing tools or a simple transparent
    formula.
-   Display the original and transformed values.
-   Explain which columns were transformed.

12. Perform feature selection using Extra Trees Classifier Aim: To write
    a Python program to perform feature selection using the Extra Trees

-   Load a suitable classification dataset.
-   Separate features and target.

-   Display feature importances and selected top features.
-   Include a new user-input sample only if a trained classifier is also
    used for prediction; do not present feature selection alone as a

-   Keep the distinction between feature selection and prediction clear.

15. Perform feature extraction using Principal Component Analysis Aim:
    To write a Python program to perform feature extraction using
    Principal Component Analysis (PCA). Requirements:

-   Load a suitable numeric dataset.
-   Scale the features before applying PCA.
-   Fit PCA and transform the data.
-   Display the original feature count, reduced feature count,
    transformed sample values, and explained variance ratio.
-   Use scikit-learn.

16. Implement KNN classification algorithm for an Iris dataset using
    scikit-learn Aim: To write a Python program to classify the Iris
    dataset using the K-Nearest Neighbors (KNN) algorithm with
    scikit-learn. Requirements:

-   Load the Iris dataset from scikit-learn.
-   Split the data into training and testing sets.
-   Scale features where appropriate and train KNeighborsClassifier.
-   Display accuracy or another suitable evaluation metric.
-   Ask the user to enter the four Iris measurements (sepal length,
    sepal width, petal length, petal width).
-   Predict and display the class for the new user-entered sample.
-   Validate numeric input.

17. Home Price Prediction using Linear Regression for error-based
    learning Aim: To write a Python program to predict house prices
    using Linear Regression and evaluate the prediction error.
    Requirements:

-   Use a clearly explained small sample dataset or a suitable provided

-   Split the data into training and testing sets.

-   Ask the user to enter the same feature values used by the model,

-   Make clear that sample data is for demonstration and predictions are
    not real property valuations.
